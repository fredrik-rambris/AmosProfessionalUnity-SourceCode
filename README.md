## Détection du langage sur GitHub

Ce dépôt est **100% assembleur 68000**. GitHub Linguist peut se tromper si des includes
ressemblent à des en-têtes C. Nous fournissons un `.gitattributes` pour forcer la détection :

```gitattributes
src/**              linguist-language=Assembly
includes/**         linguist-language=Assembly
includesSAGA/**     linguist-language=Assembly
*.i *.inc *.asm *.s linguist-language=Assembly
```
